# Mobile Robotics course site

Jekyll site for Mobile Robotics, Monsoon 2026. Deployed by GitHub Pages from `main`.

## Local preview

```sh
nix develop
jekyll serve --livereload    # http://127.0.0.1:4000
```

## Build

```sh
nix build      # output in ./result
```

## Editing

All page content is in `index.md`. Schedule entries without a link are file names as they
appear on Moodle.
